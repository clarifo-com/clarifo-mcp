# Example responses

Reviewed example responses, embedded in the generated tool pages. One file
per tool, named `<tool_name>.md`. They are never captured automatically.

Before adding one, check that it follows the publication rules:

- **Allowed:** short excerpts of figures and passages from public company
  filings, with the `citation_markdown` link kept.
- **Not allowed:** stock price series or quotes, valuation multiples computed
  on market prices, CEO Barometer scores, ownership or insider tables beyond a
  few rows, and anything from a personal workspace (portfolios, notes,
  documents, automations).
- **Trim it.** Show the shape of the response with two or three items per
  list and `…` for the rest. Remove request ids and session ids.
- Date the example ("Response from 2026-11, server 1.2.1"): data changes.

Example responses are illustrations. The data in them is not licensed for
reuse (see [NOTICE](../../../NOTICE)).
