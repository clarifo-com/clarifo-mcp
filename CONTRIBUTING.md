# Contributing

Thanks for helping improve the Clarifo Developer Hub.

## Where to go

| You want to… | Go to |
|---|---|
| Ask a question, share what you built, suggest a recipe | [Discussions](https://github.com/clarifo-com/clarifo-mcp/discussions) |
| Report a bug in an example, template or integration in this repo | [Issues](https://github.com/clarifo-com/clarifo-mcp/issues/new/choose) |
| Report wrong data, an account or billing problem, or a service outage | support@clarifo.com |
| Report a security issue | See [SECURITY.md](SECURITY.md) |

Issues are limited to the contents of this repository. The server is not
open source, so service behaviour is handled through support.

## Pull requests

- **Recipes and examples** are welcome. Follow the template in
  [`cookbook/_template.md`](cookbook/_template.md), keep the front matter
  complete and run the prompt against the live service before submitting.
- **Do not edit `docs/tools/` by hand.** It is generated from the production
  server; your change would be overwritten on the next run.
- **No real data dumps.** Example output may quote short excerpts of figures
  from public filings with their citation. Do not include stock price series,
  CEO Barometer scores or anything from a personal workspace.

  [NOTICE](NOTICE)).
